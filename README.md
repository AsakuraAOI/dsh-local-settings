# DSH Local Settings

把本地插件的常用设置放进 DSH 界面：修改配置、恢复默认值，以及为 B 站账号扫码登录和选择通知会话。

## 打开设置页

```sh
dsh plugin --profile desktop add 'github:AsakuraAOI/dsh-local-settings'
```

按安装提示重启后，在 DSH 的设置和插件详情中打开本地插件配置入口。页面按插件分组，当前未运行的组件会显示状态，启用后才能编辑。

支持的功能包括：

- **B 站账号**：生成登录二维码、查看账号状态、退出登录、管理监测与通知会话。
- **Seeit 视频理解**：调整模型、音频、视频来源和本机路径。
- **Kasumi 搜索与适配**：配置搜索服务、全局适配、工具预算、压缩和恢复保护。
- **Markdown 导出**：设置导出默认选项。

这些页面管理对应插件的配置。需要使用视频、搜索或导出功能时，还应安装相应插件。

## 保存与恢复默认

修改后点击保存。恢复默认值会移除当前覆盖项，重新使用组件继承的配置；同一行里没有修改的其他参数会保留。

如果另一处页面已经更改过配置，保存会提示刷新，避免较早打开的页面覆盖新值。密钥字段只显示是否已配置，实际凭据通过 DSH 模型设置管理。

B 站登录二维码在本机生成，登录凭据保留在 Host 侧，不返回给设置页。账号操作需要先启用 B 站插件。

## 为更多插件提供设置

受支持的包在 `src/configuration.js` 中声明，字段从组件实际运行的 Config schema 派生。隐藏字段、密钥和未声明的参数不会直接开放编辑。

```sh
npm test
```

测试覆盖配置投影、默认值恢复、过期写入、敏感字段限制，以及设置和登录路由。
